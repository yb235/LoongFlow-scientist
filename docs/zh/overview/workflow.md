# 端到端工作流

本页面说明 **LoongFlow 从开始到结束如何工作**，涵盖每种智能体类型的完整数据流。

---

## 概述：PES 循环

每个 LoongFlow 进化智能体遵循相同的高级循环：

```
┌─────────────────────────────────────────────────────────────────┐
│                     PESAgent.run()                              │
│                                                                 │
│   1. 加载/评估初始方案                                            │
│   2. 检查初始分数是否达标 → 提前退出                               │
│   3. 启动并发进化循环                                             │
│                                                                 │
│   ┌─────────────────────────────────────┐                       │
│   │        进化循环                      │ ← 并行运行 N 个         │
│   │                                     │                       │
│   │   规划 → 执行 → 总结                 │                       │
│   └─────────────────────────────────────┘                       │
│                                                                 │
│   4. 重复直到达到目标分数或最大迭代次数                             │
│   5. 通过 Finalizer 生成最终报告                                  │
└─────────────────────────────────────────────────────────────────┘
```

---

## 工作流 1：数学智能体

运行 `./run_math.sh packing_circle_in_unit_square` 时：

1. **Shell 脚本设置**：设置 PYTHONPATH，启动 Python 脚本
2. **智能体初始化**：加载配置，注册 Worker
3. **初始评估**：评估初始代码
4. **进化循环**：规划 → 执行 → 总结（并发）
5. **终止**：达到目标或最大迭代后停止

## 工作流 2：ML 智能体

运行 `./run_ml.sh run ml_example` 时：

1. **环境设置**：激活 conda 环境
2. **多阶段管道**：LOAD_DATA → CROSS_VALIDATION → CREATE_FEATURES → TRAIN_AND_PREDICT → ENSEMBLE → WORKFLOW
3. **EvoCoder**：每个阶段使用生成-评估-重试循环

## 工作流 3：通用智能体

运行 `./run_general.sh hello_world` 时：

1. **Solution Pack 协议**：多文件方案目录
2. **Claude Code Agent**：用于规划和执行
3. **两种评估模式**：自评估或自定义脚本
